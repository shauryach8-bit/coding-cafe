# Lab 4: Git & GitHub

1. `--global` means the setting is saved once for my whole Mac (in `~/.gitconfig`), a bit like a global variable. Without it, it would only apply to the current repo, like a local variable, and other repos would have no name or email.
2. A hidden `.git` folder appeared. It holds the repo's whole history and settings, like commits, branches and config. It is basically Git's database, so I shouldn't touch it.
3. Git offered to track about ___ items (README, lab notebooks, `week01/`, `week02/`, and so on). Things I didn't write: `.venv/`, `__pycache__/` and `.DS_Store`. They are generated by Python and macOS, not by me.
4. The `.venv/`, `__pycache__/` and `.DS_Store` entries disappeared from the untracked list, because `.gitignore` tells Git to skip them.
5. It should be committed. `.gitignore` is a project file like any other, so committing it means the ignore rules travel with the repo and work the same on any machine.
6. `README.md` moved from "Untracked files" to "Changes to be committed". In the three-places model, it moved from the working directory to the staging area. Staging is like putting items in a box before sealing it.
7. Git printed the branch name (`main`), a short commit ID, the message "Lab work so far", and `___ files changed`, plus the number of lines inserted.
8. The first seven characters are the short commit hash. It is a unique ID for that commit, like a key in a dictionary, so I can refer to that exact version later.
9. The four steps are edit, stage (`git add`), commit (`git commit`), and check the history (`git log`).
10. `README.md` is a convention. GitHub and other tools look for that exact name and show it automatically as the project's front page, like how Python looks for `__init__.py` in a package.
11. It stored a login token on my computer after I approved it in the browser. Git reuses it when I push, so I don't type a password each time.
12. The rendered README is showing. GitHub displays the README by default on a repo's front page so visitors can see what the project is about.
